# 수원시 행정동 경계 자료

수원시 동네별 경계를 지도에 표시하기 위해 [admdongkor](https://github.com/vuski/admdongkor)의 `ver20261001`을 후보로 조사했다. 전국 자료에서 수원시 행정동 44개를 추렸고, 경계 좌표는 변경하지 않았다.

원자료는 통계지리정보서비스(SGIS)이며, 가공 자료는 `vuski/admdongkor`에서 제공한다. 조사 내용과 파일은 팀 노션 문서 허브의 「수원시 행정동 경계 자료 조사」에 정리했다.

지도와 백엔드에서 공통으로 사용할 행정동 코드(`adm_cd` 또는 `adm_cd2`)는 협의 후 확정한다.
