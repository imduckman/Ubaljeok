# 우발적 UI 스타일가이드

우발적 화면은 핑크·인디고·골드 색에 보드게임 느낌을 살짝 섞은 스타일로 만듭니다. 모든 값은 `frontend/src/shared/styles/tokens.css`의 CSS 변수로 사용하고, 컴포넌트에 색·크기를 직접 쓰지 않습니다.

## 원칙

1. **색에는 뜻이 있다**: 핑크는 우리 그룹, 인디고는 다른 그룹, 골드는 코인.
2. **사진과 지도가 주인공**: 바탕은 흰색과 연회색, 강한 색은 필요한 곳에만.
3. **보드게임은 살짝**: 눌리는 버튼, 판 위의 칸, 둥근 캐릭터까지만. 굵은 검정 테두리와 원색 배경은 쓰지 않는다.
4. **휴대폰에서 읽힌다**: 회색 글씨도 500 이상 굵기, 누르는 것은 최소 44px.

## 색

### 뜻이 있는 색

| 변수 | 값 | 용도 |
| --- | --- | --- |
| `--us` | `#F2426D` | 우리 그룹, 메인 버튼, 강조 텍스트 |
| `--us-dark` | `#C81E52` | 핑크 버튼 그림자, 연핑크 위 글씨, 링크 |
| `--us-light` | `#FFE3E9` | 핑크 라벨·타일 배경 |
| `--us-light-edge` | `#FFC9D5` | 연핑크 타일 그림자 |
| `--them` | `#4F62F2` | 다른 그룹 땅·건물 |
| `--them-dark` | `#3747CC` | 인디고 그림자, 연한 배경 위 글씨 |
| `--them-light` | `#E4E8FF` | 다른 그룹 관련 연한 배경 |
| `--coin` | `#FFB800` | 코인, 랜드마크 깃발 |
| `--coin-dark` | `#D99A00` | 코인 아이콘 그림자 |
| `--coin-light` | `#FFF1C9` | 지갑·통행료 배경 |
| `--coin-text` | `#6B4A00` | 노란 배경 위 글씨 |
| `--coin-gain` | `#8C5A00` | 코인 증가량 (+100) |

| 변수 | 값 | 용도 |

### 방문 농도 5단계

| 단계 | 방문 횟수 | 변수 | 값 |
| --- | --- | --- | --- |
| 1 | 1회 | `--visit-1` | `#FFE3E9` |
| 2 | 2회 | `--visit-2` | `#FFBDCB` |
| 3 | 3–4회 | `--visit-3` | `#FC93AB` |
| 4 | 5–9회 | `--visit-4` | `#F56A8B` |
| 5 | 10회 이상 | `--visit-5` | `#E8416B` |

### 사용 규칙

- 핑크 채운 버튼은 화면당 하나. 나머지는 흰 버튼이나 검정 버튼.
- 인디고는 다른 그룹에만, 골드는 코인·통행료·랜드마크에만.
- 연한 배경 위 글씨는 같은 계열의 진한 색을 쓴다.
- 카카오톡 공유 버튼만 예외로 `#FEE500`.

## 글자

폰트는 **Pretendard** 하나만 씁니다. 제목은 굵게 하되 글자 간격은 거의 줄이지 않습니다.

| 이름 | 크기 | 굵기 | 줄간격 | 글자 간격 | 쓰는 곳 |
| --- | --- | --- | --- | --- | --- |
| display | 48px | 900 | 1.1 | -0.8px | 앱 이름, 코인 +100 |
| title | 28px | 800 | 1.3 | -0.4px | 화면 제목 |
| heading | 21–26px | 800 | 1.3 | -0.3px | 시트 제목, 동네 이름 |
| lead | 20px | 800 | 1.45 | -0.2px | 로그인 문구 |
| body | 15–16px | 500 | 1.6 | 0 | 본문, 입력값 |
| button | 16–19px | 700–800 | 1 | 0 | 버튼 (핑크 버튼은 19px) |
| label | 13px | 700 | 1.4 | 0 | 입력칸 이름, 라벨 |
| caption | 12–13px | 500 | 1.5 | 0 | 보조 설명 |

- 회색 글씨는 최소 500 굵기, 최소 크기 11px.
- 한글 줄바꿈은 단어 단위 (`word-break: keep-all`).

## 모양

보드게임 느낌은 **눌림 그림자** 하나로 냅니다. 요소 바로 아래에 흐림 없이 같은 계열의 진한 색을 깔아 타일 같은 두께를 줍니다.

### 모서리 둥글기

| 변수 | 값 | 대상 |
| --- | --- | --- |
| `--radius-chip` | 6px | 작은 라벨 |
| `--radius-tile` | 14px | 코드 타일, 사진 칸, 작은 통계 카드 |
| `--radius-input` | 16px | 입력칸, 상단 버튼 |
| `--radius-button` | 18px | 버튼 |
| `--radius-card` | 22px | 카드 |
| `--radius-sheet` | 28px | 바텀시트, 큰 카드 |

### 그림자

| 종류 | 변수 | 대상 |
| --- | --- | --- |
| 눌림 | `--press` + 같은 계열 진한 색 | 버튼, 카드, 코드 타일 |
| 작은 눌림 | `--press-small` + 진한 색 | 코인 아이콘, 라벨 |
| 떠 있음 | `--float` | 상단 알림, 바텀시트 |

눌림 색 짝: 핑크 → `--us-dark`, 흰 버튼 → `--line-strong`, 흰 카드 → `--line`, 검정 버튼 → `#3A3B44`, 연핑크 타일 → `--us-light-edge`.

- **테두리**: 카드와 흰 버튼은 1.5px 연회색, 선택된 카드만 2px 핑크. 검정 굵은 테두리는 쓰지 않는다.
- **여백**: 화면 양옆 20–24px, 위 64px, 아래 34px. 요소 사이는 8 / 12 / 16 / 20px 중에서 고른다.

## 컴포넌트

아래 10개를 공통 부품으로 먼저 만들고, 화면에서는 이 부품을 조합합니다.

| 부품 | 종류 | 크기·모양 | 예 |
| --- | --- | --- | --- |
| Button | primary(핑크), secondary(흰색), dark(검정), kakao(노랑) | 높이 56–58px, 둥글기 18px, 눌림 | 출발하기, 새 그룹 만들기 |
| IconButton | 회색 배경 | 44×44px, 둥글기 14px | 닫기, 더 보기 |
| TextField | 기본, 오류 | 높이 52px, `--page` 배경, 1.5px 테두리, 위에 라벨 | 아이디, 비밀번호 |
| Card | 기본, 선택됨 | 흰 배경, 1.5px 테두리, 둥글기 22px, 눌림 | 그룹 카드 |
| CodeTile | 핑크·노랑·인디고 순환, 입력 중, 빈 칸 | 6칸, 높이 56–58px, 글자 22–26px | 초대 코드 |
| Chip | 핑크, 골드 | 둥글기 6px, 11–12px 글씨 | 지금 그룹, 그룹장, 우리 땅 |
| BottomSheet | - | 위 둥글기 28px, 손잡이 36×5px, 뒷배경 검정 42% | 초대 코드 입력, 동네 정보 |
| Toast | 코인, 오류 | 상단, 둥글기 18px, 아이콘 40px + 제목 + 설명 | +100 코인 |
| WalletPill | - | 높이 46px, `--coin-light` 배경, 코인 아이콘 + 숫자 | 지도 상단 340 |
| BottomNav | 4개 메뉴 + 가운데 사진 올리기 | 가운데 58×58px 핑크 버튼이 위로 돌출 | 지도, 영상 일기, 건물, 그룹 |

- **캐릭터**: 둥근 막대 모양(가로:세로 약 3:4)에 눈 두 개와 웃는 입. 기본 핑크, 친구는 골드·인디고. 로그인 그림, 멤버 자리, 지도 위 말로 쓴다.
- **아이콘**: 선형 아이콘, 선 굵기 2.2–2.6px, 18–22px. 이모지는 쓰지 않는다.

## 지도 표현

지도에서 **면 색은 현재 그룹의 방문 농도, 건물·배지는 소유자**를 나타냅니다.

| 대상 | 표현 |
| --- | --- |
| 우리 그룹이 방문한 동네 | `--visit-1` ~ `--visit-5` |
| 우리가 안 간 동네 | `#ECEDF1` |
| 다른 그룹이 소유한 동네 | `--them` (내가 방문만 한 곳은 `--them-light`) |
| 건물 | 흰 집 아이콘 + 소유 그룹 색 창문 |
| 랜드마크 | 흰 빌딩 아이콘 + 골드 깃발 |
| 선택한 동네 | 검정 이름 라벨 + 아래 바텀시트 |
| 동네 경계 | 흰 선 3.5px, 아래로 4px 두께(`#D5D7DE`) |
| 강 | `#D6E6FF` |

지도 왼쪽 위에는 항상 농도 범례(1회 → 10회+)를 둡니다.

## 문구

친구에게 말하듯 **짧은 해요체**로 쓰고, 버튼은 동사로 끝냅니다.

| 상황 | 쓰기 | 쓰지 않기 |
| --- | --- | --- |
| 버튼 | 출발하기, 그룹 참여하기 | 확인, 제출 |
| 오류 | 아이디 또는 비밀번호가 맞지 않아요. | 오류: 인증 실패 |
| 안내 | 친구에게 받은 6자리 코드를 입력하세요. | 초대 코드를 입력해 주시기 바랍니다 |
| 보상 | 매탄동 첫 방문으로 받았어요 | 코인이 성공적으로 지급되었습니다! |
| 빈 화면 | 먼저 함께 걸을 친구들을 모아볼까요? | 그룹이 없습니다 |

- 오류는 무엇이 잘못됐는지와 어떻게 하면 되는지를 한 문장으로.
- "성공적으로", 느낌표 남발은 피한다.

### 숫자 변화 표시

바뀐 뒤 값을 크게, 변화량은 괄호로 옆에 씁니다. 줄 긋기나 화살표는 쓰지 않습니다.

| 상황 | 표시 | 변화량 색 |
| --- | --- | --- |
| 늘어남 (방문 보상, 통행료 받음) | **340** (+100) | `--coin-gain` |
| 줄어듦 (구매, 업그레이드, 통행료 냄) | **240** (−100) | `--ink-2` |
